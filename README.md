# First Bite for Claude

First Bite is the go-to-market platform for foodservice: operator data,
prospecting and CRM in one place. This repository is First Bite's Claude
plugin marketplace. It holds one plugin, `firstbite`, which connects Claude to
your First Bite account and adds First Bite's playbooks for call notes, call
follow-ups and new deals.

Install in Claude Code:

    /plugin install firstbite --marketplace TheLonesomeData/firstbite-claude-plugin

See [plugins/firstbite/README.md](plugins/firstbite/README.md) for what the
plugin does and how to connect it. Questions: support@firstbite.io.

This repository is published from First Bite's main codebase; changes made
here directly are overwritten.
